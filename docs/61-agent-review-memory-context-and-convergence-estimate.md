## 5. 假设、风险与排除项

- 基准包括概要设计中的 P1～P7；按阶段独立授权实施，不表示一次授权全部落地。
- 1.00 人天的 Java 定位、关系解析及 CLI 回合桥条目，高于常规脚手架：分别涉及 base/head 语义、动态/同名关系边界和四运行时中唯一无法直接控制模型循环的 CLI 协议。
- 首期依赖已确认的 Java/MyBatis 仓库；不含 Python/JS/TS/Swift/Kotlin 完整调用图、跨仓 RPC、精确动态分派、图数据库或向量库。
- 不含超大 diff 自动拆批及跨批综合判断；预算不足明确呈现部分覆盖，不将遗漏记成全量通过。
- 团队规范首期按项目登记，不恢复项目组模型，不含跨团队共享授权或完整账号体系。
- 不恢复整个旧反馈运营平台；仅提供记忆维护、误报确认与必要详情摘要。
- 自测/联调只在对应行计一次；本次设计任务不新增、修改或运行单元测试。实施阶段如需单元测试，由当阶段明确授权后另行执行，不默认扩展覆盖率工作。
- 不含正式 QA 全量回归、长时间压测、数据人工整理、生产发布操作及观察等待。已有误报率/漏报率未实测，收益需固定样本对比。
- 14～17 人天是基于解析与 CLI 事件不确定性的排期区间；不是对表内额外重复计费。单人日历工期还受阶段停止点及环境授权影响。
