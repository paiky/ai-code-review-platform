# 记忆库默认开启与项目配置入口

## 目标与契约

用户要求隐藏项目关联页的记忆设置卡片、保存版本标签和关联匹配说明，将开关移到项目配置；所有项目默认开启。共享任务：`20261116-memory-project-settings`。

- `GET /api/projects/{id}/configuration` 新增 `memorySettings: {enabled, version, schemaReady}`，复用独立设置读取。
- `PUT` 同一路径新增可选 `memorySettings: {enabled: boolean, expectedVersion: positive integer}`。缺省或 null 保留原记忆设置，兼容旧客户端；传入时复用旧设置的项目锁和 CAS 校验，与其他项目配置同事务提交。迁移未就绪返回 503；版本冲突返回 409，整次配置保存回滚。
- 原 `/api/projects/{id}/review-memory/settings` 读写契约保持。项目关联列表仍读取真实设置，关闭时显示关闭状态，读取失败不能假装开启。
- 前端项目配置归一化保留记忆状态和版本；只有实际更改开关时随统一保存传入更新。版本冲突保留本地草稿，可重新读取最新版本后人工保存。页面不显示已保存版本标签。
- V61 将 `memory_enabled` 数据库默认改为 TRUE，一次性把存量 FALSE 改为 TRUE 并递增这些行的设置版本，使旧页面快照失效。后续明确关闭保留；读取无设置行默认 TRUE。V59/V60 历史迁移不改写，未具备 V59 列时仍禁用注入。
- 不自动关联或发布资料、不触发审查，不改变规则检索、预算、必载失败保护、旧接口、Standard Review 或历史冻结背景。

## 推进阶段

### P1：兼容后端、默认值及配置页面

- 改动量等级：大。涉及前后端公开配置字段和默认值数据迁移，需验证事务回滚及旧客户端兼容。
- 目标/范围：实现上述可选契约、项目配置开关、项目关联页精简及 V61；接口、兼容保护和 UI 同阶段交付，避免开关入口领先于后端校验。
- 非目标：其他记忆功能、向量检索、真实模型效果验证、远程部署。
- 验收：静态检查、隔离 MySQL/API 验证默认/关闭/旧请求/CAS 回滚/记忆选择，前端 build、浏览器桌面及窄屏交互；本地 LOCAL 库先核对备份，再执行 V61 并复核。
- 授权边界：用户四条批注与开始任务授权；只操作本项目及共享任务记录；沿用原阶段本地提交约定，不推送部署，不新增或运行单元测试。
- 停止点：验收、记录及本地提交后停止。当前单一执行聊天，不启动未授权的桌面接力。
- 不进一步拆分原因：开关迁移、默认语义和保存兼容需要共同可用；本地库迁移在代码验证之后单独执行，未执行前明确记录。恢复以迁移前设置备份及默认值为依据，不覆盖资料、关联或后续人工配置。
