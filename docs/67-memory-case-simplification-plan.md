# 误报案例简化与风险优先展示

## 目标与契约

用户确认将案例归档改为“风险优先展示、只填误判原因”，并允许后续桌面聊天串行接手。共享任务标识：`20261116-memory-case-simplification`。

- 案例抽屉默认显示风险标题、等级、文件位置、简短原描述及误判原因。完整原描述/建议、来源和版本信息默认折叠；适用范围等配置及可选补充放高级设置。
- 已转旧策略、已撤回、来源删除等不可确认记录不显示禁用表单及确认按钮，保留真实状态、原风险和追溯入口。
- 既有 `POST /api/projects/{projectId}/review-memory/feedbacks/{feedbackId}/confirm` 保留字段名与版本保护。`title` 与 `misjudgmentCause` 必填；标题由原风险自动带入，仅误判原因要求人工填写。`applicability`、`correctApproach`、`requiredEvidence`、`exceptions` 改为可省略或空字符串的选填项；显式 null、NUL、超长和非法范围继续拒绝。
- 原反馈说明自动带入误判原因，允许在确认窗口补充；上下文不足的反馈可在这里直接补齐原因，不再要求先跳回修改原反馈。确认内容与原反馈分别保存，原反馈摘要、CAS、幂等及撤回失效链路保持。
- PITFALL 正文保留既有章节名称，至少有非空“原误判及原因”；其他章节仅在提供时写入，不补造判断方法、证据或失效条件。旧五段案例兼容读取、重新确认、回写和检索。INCIDENT 仍要求完整五段，不放宽其它资料规则。
- 4000 UTF-8 字节预算、按需加载、项目私有、同源确认、版本冲突及历史冻结保护保持。不调用模型自动生成事实，不改真实业务数据，不需数据库迁移。

## P1：兼容简化契约与页面

- 改动量等级：大。涉及前后端公开确认契约、回写和检索验证；必须一起交付，防止表单可保存但后端或后续检索拒绝。
- 目标/范围：上述案例确认、PITFALL 校验及抽屉布局；旧案例继续可用。
- 非目标：其它页面整治、AI 自动整理、跨项目共享、数据库迁移、推送及部署。
- 验收方式：聚焦 Python 静态、前端 build；隔离 MySQL/API 验证最少输入→确认→异步回写→检索、旧五段兼容、可选空值/非法值/预算/CAS/撤回；隔离浏览器验证默认重点、仅原因保存、高级字段保留、不可确认隐藏表单、错误保护及窄屏；真实页面仅 GET。
- 授权边界：用户本轮确认；沿用记忆库验收后本地提交约定，不推送部署，不新增/修改/运行单元测试。桌面接手授权覆盖本次目标内创建、联系新聊天及串行转移执行职责，按实际需要使用；不为了演示接手强制创建聊天，不扩展任务范围。
- 停止点：目标验收、文档状态与本地提交完成后停止；关键决策或权限缺失则保存状态。交接前冻结现场、旧执行者停止业务写入，新聊天只读核对后接手。
- 不进一步拆分：简化表单、确认契约、回写和检索校验必须共同可用，单独交付会造成可确认但不能回写或召回的中间状态。

## 实施与验收

P1 已完成（2026-11-16）。

### 实施结果

- 抽屉改为单列，风险标题/等级/文件位置及两行原描述优先展示；完整原描述与建议、来源及版本、可选补充均默认收起。已转旧策略或不可确认的记录只展示风险和状态，不显示禁用表单或确认按钮。
- 默认唯一人工必填为“误判原因”，原反馈文字自动带入；标题自动带入且限制在既有 255 字符契约内。四段可选内容及原适用范围在高级设置维护，折叠不会清空旧值。
- PITFALL 仅要求非空原因章节，保留既有章节名称与顺序校验；省略的可选段不写占位正文。旧五段案例、确认任务和回写继续兼容；INCIDENT 五段规则不变。手工新建 PITFALL 模板与说明同步为原因必填。
- 处理中/成功改为紧凑状态行，失败、冲突等恢复提示保留。冲突刷新时展开来源用于对照，加载期间禁止勾选对照确认。
- 无数据库迁移。发布到其它环境时前后端需一起更新：旧后端仍要求五段，不能只更新前端后发送简化确认。

最少确认示例（标题及版本由页面自动带入）：

```json
{
  "expectedFeedbackDigest": "原反馈的64位摘要",
  "expectedSourceVersion": null,
  "title": "原风险标题",
  "misjudgmentCause": "提交事务后已有监听器删除同一缓存，原结论缺少该调用链背景。"
}
```

四个选填字符串允许缺省、空字符串或空白（归一化为空）；显式 null、NUL、超长、空原因及非法范围返回既有校验错误。完整正文超过 4000 UTF-8 字节仍拒绝。保存原因不会改写原反馈文字；用户修改或撤回原反馈后，原失效保护继续生效。
